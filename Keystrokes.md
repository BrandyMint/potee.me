Keystrokes
==========

* `space` — move to today
* `enter` — create a new project
* `esc` — cancel the current form / deselect the project
* `+` / `-` — zoom in / out
* `0` — switch between the days and months zoom
* `ctrl` / `⌘` + mouse wheel (or trackpad pinch) — zoom around the pointer

Mouse
=====

* double click on empty space — new project starting on that day
* double click on a project — new event at that moment
* drag empty space or a project bar — scroll the board
* drag a project's left/right edge — change its start / finish
* drag a project's title up or down — reorder projects
* drag an event — move it in time; click its title to rename or remove it
* click a project — select it: rename, change colour, fit it on screen ("Entire"), copy the share link, delete
