# Roadmap: Potee

Potee — самостоятельный продукт (хакатон Rails Rumble 2012, перезапуск
2026-10-01). Направление развития — открытый вопрос `OQ-07` в
[PRD-001](prd/PRD-001-potee.md); здесь — рабочая ставка и шаги её проверки.

## Кандидаты направлений

| # | Направление | Суть | Плюс | Минус |
| --- | --- | --- | --- | --- |
| 1 | Личный планировщик | Проекты жизни и работы одного человека; напоминания, импорт календаря, мобильная версия | Широкая понятная аудитория | Рынок забит, Potee — «ещё один» |
| 2 | Общий план семьи или пары | Ремонт, отпуск, переезд; права «только просмотр», уведомления, шаблоны | Шаринг без регистрации уже есть и редок | Вирусно, но платят плохо |
| 3 | **Планировщик для работы с AI-агентами** | План из одного сообщения; еженедельная сводка следующих шагов; MCP/skill, чтобы агенты читали и правили доску | Свежая ниша, рядом с темой «Агенты в деле», сильное отличие | Неопределённость: нужно проверить спрос |
| 4 | Дорожная карта для клиента | Фрилансер или агентство показывает клиенту сроки по ссылке «только просмотр» со своим брендом | Понятная монетизация | Узкий сегмент, конкуренция с Гант-инструментами |

## Решение

**2026-10-01:** ставка — **направление 3** (планировщик для работы с
AI-агентами); направление 2 — запасное, потому что почти всё нужное уже есть.
Окончательный выбор — по результатам проверки (шаг 6).

## Шаги

| # | Шаг | Что делаем | Результат | Статус |
| --- | --- | --- | --- | --- |
| 1 | Доступ агентов к доске | MCP-сервер Potee и skill для Claude Code / Codex: агент читает доску, создаёт и правит проекты и вехи | Агент ведёт реальные проекты владельца | сделано 2026-10-01: `/mcp`, токен на `/account`, skill `skills/potee`; 2026-10-02 — страница с инструкцией и списком инструментов по `GET /mcp` в браузере |
| 2 | Первый живой проект — курс «Технический руководитель агентов» | План запуска курса (`hq/projects/agent-tech-lead`) ведётся на доске Potee через агента | Проверка на себе: удобно ли вести реальный запуск через агента | начато 2026-10-01: 4 полосы и 16 вех курса на доске Данила, созданы агентом через skill |
| 3 | Измерения | UTM-метки первого визита по стандарту флотилии `attribution/v1` (`corp-sales/marketing/attribution.md`); отчёт в админке: активация, возврат, регистрации, глубина, совместная работа — по источникам и неделям | Можно сравнивать каналы и направления | сделано 2026-10-03: `users.attribution` (первое касание: UTM, страница входа, referrer; ссылка на проект — `potee` / `share`), отчёт `/admin/sources` по источнику, типу размещения или кампании: пришли, начали планировать, вернулись, зарегистрировались, поделились, план из текста, агент |
| 4 | Исследовательский документ | Гипотезы по направлениям 3 и 2, эксперименты, сроки, критерии выбора | Ясно, что считается успехом | черновик 2026-10-03: [RS-001](research/RS-001-direction-check.md) — гипотезы `H-01`–`H-05`, эксперименты `E-01`–`E-05`, пороги и правило выбора; ждёт утверждения Данила |
| 5 | «План из одного сообщения» | Текст «запуск курса к 1 декабря: лендинг, 3 вебинара, рассылка» → проект с вехами на доске; LLM через LiteLLM кластера | Минимальная проверка направления 3 на пользователях | спецификация: [FT-001](features/FT-001-plan-from-text/README.md); только для зарегистрированных, модель Claude Haiku 4.5 через OpenRouter (алиас LiteLLM `potee-plan`) |
| 6 | Запуск проверки | Пост в клубе «Агенты в деле», упоминание на pismenny.ru, Telegram — каждый со своей меткой; публикации только после одобрения Данила | Трафик из разных источников | запланировано |
| 7 | Разбор через 2–3 недели | Отчёт по метрикам + 5–7 разговоров с вернувшимися пользователями | Выбор направления, обновление PRD | запланировано |
