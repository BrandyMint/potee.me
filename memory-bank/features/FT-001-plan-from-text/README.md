# FT-001: План из текста

Зарегистрированный пользователь описывает план обычным текстом, языковая модель
раскладывает его на проекты и вехи, пользователь проверяет предпросмотр и
добавляет его на доску. Шаг 5 [roadmap](../../roadmap.md): минимальная проверка
направления «планировщик для работы с AI-агентами» на людях без собственного агента.
