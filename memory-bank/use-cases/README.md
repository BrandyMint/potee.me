# Use cases: Potee

Сценарии ведутся по методике [dapi/memory-bank](https://github.com/dapi/memory-bank):
[Use Case Flow](https://github.com/dapi/memory-bank/blob/main/template/memory-bank/flows/use-case.md)
и шаблон [UC-XXX](https://github.com/dapi/memory-bank/blob/main/template/memory-bank/flows/templates/use-case/UC-XXX.md).
UC описывает устойчивое наблюдаемое поведение; acceptance конкретной фичи — в её
`brief.md` (`SC-*`, `NEG-*`), проверки — в тестах, на которые ссылается раздел
Downstream Behavior Coverage.

Новый сценарий заводится, если он повторяется во времени, не принадлежит одной
фиче и нужен как опора для нескольких документов. Если фича меняет поведение,
сначала обновляется UC, затем её brief и тесты.
